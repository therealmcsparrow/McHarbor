# Terminal: Fields

What the Terminal screen lets you choose before a session starts: which running container
to attach to, and which of the shells detection found in its image. Resizing the browser
window resizes the remote TTY.

## Filters and facets

| Filter | What it narrows |
|---|---|
| Container | Only running containers can be attached to |
| Shell | What detection found in the image |

Resizing the browser window resizes the remote TTY.

## Shared list behaviour

Every list screen inherits the same controls: free-text search, a filter mode of
**Contains**, **Exact** or **Regex** (an invalid expression says so rather than silently
matching nothing), saved filters and searches, selection with a bulk bar, and pagination
showing "X to Y of Z" with a rows-per-page control.
