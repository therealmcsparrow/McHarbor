# Plugin compatibility

Which McHarbor versions each bundled plugin declares it runs on. Generated by
`node scripts/reference/generate-plugin-compatibility.mjs` from every
`src/plugins/Plugins/*/plugin.yaml` (`version:`, `mcharbor:`, `go:`) and the `Version:` symbol in the
plugin's `backend/main.go`. Do not edit this page by hand — re-run the generator.

## How to read it

- **Requires McHarbor** is the manifest's `mcharbor:` range. The columns after it evaluate that range against
  the current `VERSION` (2026.09.01) and the release before it (2.0.8).
- A range is necessary, not sufficient. A plugin backend is a Go `.so` loaded with `plugin.Open`, and Go refuses
  a `.so` built against a different build of the host packages. Every McHarbor upgrade therefore needs the
  bundled plugins rebuilt and updated through the Plugin Store, whatever the range says — see
  [Upgrading](../getting-started/upgrading/README.md).
- **Symbol matches manifest** compares `plugin.yaml` `version:` with the `Version:` the backend reports. The
  loader requires them to agree; a `no` here is a plugin that will fail to load after its next rebuild.
- Plugins version on their own schedule, so a plugin at a later sequence than the host is normal.
