# Gotify

Delivers notifications to a self-hosted Gotify server using an application token.

- **Slug** `comm-gotify`, **version** 2026.09.01, **channel type** `gotify`
- **Host range** `>=2026.09.01`
- **Where it appears** Settings → Integrations → Communications, as a channel type
- **Gated by** `communications.view` to see channels, `communications.manage` to add or change one, and `channels:use-comm-gotify` (global) to route events through this channel

## How it works

- `priority` is Gotify's integer priority. Gotify clients decide how loudly to announce a message based on it.
- No file attachments.

## Capabilities it advertises

| Capability | Set | Meaning |
|---|---|---|
| `EncryptedCredentials` | Yes | The channel holds a secret, stored encrypted at rest and decrypted only at send time. |
| `SupportsRichAttachments` | No | Structured cards or blocks beyond title and message. |
| `SupportsFileAttachments` | No | Files, such as a report export, can ride along with the message. |
