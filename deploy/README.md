# deploy/

Examples an operator copies and adapts: Compose layouts, the Helm chart, plain Kubernetes
manifests and reverse-proxy configurations. Nothing here is produced by the build.

Artifacts the build produces — the `.deb`, `.rpm` and tarball, and the systemd units they
install — live in [`packaging/`](../packaging/README.md).

The walkthrough is [Deployment](../.documentation/getting-started/deployment/README.md).
