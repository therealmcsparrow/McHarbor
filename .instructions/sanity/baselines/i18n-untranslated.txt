#
# Format: one entry per line, "locale|namespace|key".
#   nl|common|labels.port
#   de|containers|table.image
#
# The namespace is the locale file without .json; the key is the full dotted
# leaf path inside it. Matching is case-insensitive. Lines starting with # and
# blank lines are ignored.
#
# Use this file for the real thing - a word that a native speaker would leave
# in English in that language ("Server" in nl/de, "Import" in fr) - not as a
# way to silence a translation that simply has not been written yet. A frozen
# entry disappears from check 3 and is counted in the "Frozen" column of the
# coverage table, so the debt stays visible either way.
#
# Prefer freezing a specific key here over widening the do-not-translate word
# list in check.ps1: that list is global, and a word added to it stops being
# checked in all six locales at once.
#
# Brand names, acronyms and API machine values do NOT belong here - check 4
# already accepts them automatically from .instructions/donottranslate.md.
